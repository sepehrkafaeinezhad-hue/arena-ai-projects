## فاز ۰ — پیش‌نیازها و نصب (~۳۰ دقیقه)

### چه چیزهایی لازم داری؟
- 💻 یک لپ‌تاپ/کامپیوتر (ویندوز ۱۰/۱۱ یا مک) + اینترنت
- ☕ اشتراک **Claude Pro** (~۲۰$ در ماه) — شامل Claude Code است. از [claude.ai](https://claude.ai) ثبت‌نام و پرداخت کن. (پلن رایگان برای Claude Code مناسب نیست؛ API هم گزینه است ولی برای شروع Pro ساده‌تر و ارزان‌تر است.)
- 📱 اینستاگرام خودت (اکانت Professional بودن بهتر است تا آمار Insights داشته باشی — رایگان است: Settings → Account type)

### نصب، گام‌به‌گام

**گام ۱ — نصب Node.js** (موتور اجرای Claude Code):
- ویندوز/مک: از [nodejs.org](https://nodejs.org) نسخه **LTS** را دانلود و نصب کن (Next-Next تموم).
- چک کن: یک پنجره ترمینال باز کن (ویندوز: منوی استارت → PowerShell؛ مک: Terminal) و بزن:
  ```
  node -v
  ```
  باید عددی مثل `v22.x.x` ببینی. ✅

**گام ۲ — نصب Claude Code:** در همان ترمینال:
```
npm install -g @anthropic-ai/claude-code
```

**گام ۳ — ورود به حساب:** در پوشه دلخواه‌ات (مثلاً `cd ~`) بزن:
```
claude
```
اولین بار مرورگر باز می‌شود؛ با اکانت Claude پرو لاگین کن. بعدش یک صفحه گفتگو می‌بینی. ✅

> 💡 **هزینه‌های بعدی (همه اختیاری):** Canva رایگان کافی است (~۱۱€/ماه اگه Pro خواستی). زمان‌بندی: Postiz self-host رایگان (سرور ~۵€/ماه) یا Metricool پلن رایگان برای ۱ برند. پاسخ خودکار دایرکت (بعداً توضیح می‌دم): ManyChat پلن رایگان. قیمت‌ها حدودی‌اند — موقع خرید چک کن.

## فاز ۲ — شخصی‌سازی صدای برند (~۴۵–۶۰ دقیقه) ⭐ مهم‌ترین فاز

> چرا این‌قدر مهم؟ سیستم همه‌چیز را از روی `brand/voice.md` می‌سازد. این فایل خالی = خروجی ژنریک و بی‌روح. این فایل پر = محتوایی که واقعاً «صدای تو»ست.

### تمرین ۱: مصاحبه با خودت (۱۵ دقیقه) — جواب‌ها را در `brand/voice.md` بنویس
۱. **اگر یک غریبه ویدیوهایم را ببیند، با چه جمله‌ای توصیفم می‌کند؟** (مثلاً: «همون پسره که رک درباره پول و AI حرف می‌زنه»)
۲. **سه جمله‌ای که خیلی می‌گم؟** (زبان روزمره‌ات — مثلاً «بذار رک بگم»، «نگاه کن، ساده‌ش اینه»)
۳. **از چه لحنی متنفرم؟** (مثلاً: انشای انگیزشی، وعده پول‌پارچه‌کن، لحن پشتیبان‌فروشی)
۴. **تجربه/زاویه واقعی من چیه که بقیه ندارن؟** (مثلاً: «خودم فریلنسری می‌کنم و ابزارها را با پول خودم تست می‌کنم»)
۵. **جواب‌های ۱–۴ را بخوان: آیا این صدای من است؟** اگر نه، دوباره بنویس.

### تمرین ۲: نمونه‌های واقعی (۱۵ دقیقه)
- اگر قبلاً پست/کپشن/متن نوشته‌ای: **۳–۵ تای بهترین‌شان** را در `voice.md` بخش «نمونه‌های واقعی» paste کن.
- اگر هیچ‌چیز نداری: ۳ پاراگراف درباره «چرا فریلنسرها باید AI بلد باشند» طوری بنویس که حس کنی داری به یک دوست توضیح می‌دهی. همین را بگذار — سیستم از رویش الگو می‌گیرد و با هر هفته بهتر می‌شود.

### تمرین ۳: پر کردن Swipe File (۱۵ دقیقه)
۱۵ دقیقه در اینستاگرام بگرد (نیچ بیزنس + AI، فارسی و انگلیسی)، **۵ پست که خیلی خوب جواب گرفته‌اند** را در `brand/swipe-file.md` ثبت کن: لینک + چرا جواب داد + چه الگویی برای تو دارد.
> قانون: الگو بردار، محتوا کپی نکن.

### تمرین ۴: چک نهایی CLAUDE.md (۵ دقیقه)
من از قبل برای نیچ/پلتفرم/زبان تو تنظیمش کرده‌ام. فقط یک نگاه بنداز — اگر CTA پیش‌فرض («کلمه X رو کامنت کن تا … بفرستم») را دوست نداری، عوضش کن.

## فاز ۴ — ضبط و انتشار ویدیو (~۲ ساعت برای اولین بار، بعداً ~۱ ساعت)

سیستم اسکریپت و پک بصری می‌دهد؛ **ضبط و ادیت با خودت است** (و همین خوب است — صدای واقعی تو اعتماد می‌سازد):

1. **ضبط:** دوربین گوشی، نور رو به پنجره/رینگ‌لایت، صدا واضح (میکروفون کوچک اگر داری). اسکریپت را از روی صفحه/تلپرامپتر بخوان — لازم نیست کلمه‌به‌کلمه باشد، خودتی‌بودن بهتر است.
2. **ادیت:** CapCut (رایگان):
   - برش‌های خالی را بزن (ریتم تند)
   - زیرنویس‌های Burned-in که Designer داد را روی زمان‌بندی‌هاش بگذار — فونت فارسی: **Vazirmatn Bold** یا Dana؛ راست‌چین؛ روی نوار تیره/سایه
   - B-rollها از لیست Designer را لای ویدیو بگذار (اسکرین‌رکورد ابزارهای AI برای این نیچ عالیه)
   - کاور: طرح Designer + متن وسط کادر (۱۵٪ بالا و ۲۰٪ پایین خالی بماند)
3. **انتشار (دستی از گوشی):** طبق چک‌لیست Publisher — ویدیو 9:16، کاور، کپشن paste، هشتگ‌ها، بعد اشتراک در استوری.
4. **بعد از انتشار:** به Claude بگو «I-01 منتشر شد» → status می‌شود `published`.

## فاز ۶ — ارتقا (هفته ۲ به بعد، هر بار فقط یکی)

قانون: اول ۲ هفته سیستم ساده کار کند، بعد ارتقا بده:

| ارتقا | چی بهت می‌دهد | چطور |
|---|---|---|
| **Canva MCP** | کاور خودکار از داخل چت | فایل `.mcp.json.example` → کپی به `.mcp.json` → فقط بخش canva بماند → ری‌استارت Claude → `/mcp` چک |
