## مرحله ۲ — Strategy Tester

### ۲.۱ تنظیمات تستر

| تنظیم | مقدار |
|---|---|
| Expert | `GoldSweepEA` |
| Symbol | XAUUSD (دقیقاً همان نام) |
| Period | M15 |
| Date | حداقل ۶ ماه (مثلاً 2026.01.01 – 2026.10.01) |
| Modelling | **Every tick based on real ticks** |
| Deposit | 10,000 USD |
| Leverage | 1:100 |
| Delays | Random delay |
| Optimisation | **Disabled** |
| Visual mode | برای اولین اجرا **روشن** |

Inputs: پریست `GoldSweepEA_XAUUSD_M15.set` را لود کنید، سپس:
- `InpLogLevel=2`
- `InpDryRun=false`
- `InpShowDashboard=true` (در تستر چیزی نمایش نمی‌دهد، ضرری ندارد)
- `InpPersistState=false` برای اجرای سریع‌تر (وضعیت بین ران‌ها لازم نیست)

### ۲.۲ سه اجرای اصلی

| اجرا | هدف | بازه | تنظیم خاص |
|---|---|---|---|
| A — Smoke | صحت اجرا و نبود خطای بحرانی | ۱ ماه | اسپرد ثابت تستر |
| B — Real ticks | رفتار واقعی با اسپرد متغیر و کمیسیون | ۶ ماه | Every tick based on real ticks |
| C — Stress | شرایط بحرانی | ۳ ماه پرنوسان (مثلاً بحران‌های طلا) | `InpMaxSpreadPoints=100`، بالانس ۲٬۰۰۰ |

### ۲.۳ معیارهای قبولی بک‌تست

| # | معیار | حد قبولی |
|---|---|---|
| 2.3.1 | تعداد خطاهای `invalid stops` / `invalid volume` | 0 (یا کمتر از ۱٪ سفارش‌ها) |
| 2.3.2 | هر ورود SL و TP دارد | 100٪ |
| 2.3.3 | `position has NO stop loss` | 0 |
| 2.3.4 | قفل روزانه در لاگ | باید دیده شود (در اجرای C حتماً) |
| 2.3.5 | بعد از قفل، هیچ ورود جدیدی نیست | 100٪ |
| 2.3.6 | حداکثر ضرر یک معامله | ≤ ۱.۵ × ریسک برنامه‌ریزی‌شده |
| 2.3.7 | Max DD | ≤ ۱۵٪ (با سقف ۱۰٪ انتظار می‌رود کمتر بماند) |
| 2.3.8 | تعداد معاملات | منطقی با ۳ سقف روزانه (نه صفر، نه صدها) |
| 2.3.9 | لاگ‌های `actual risk ... above planned` | کم و قابل توضیح (اسلیپیج) |
| 2.3.10 | کرش/توقف | 0 |

> **هشدار:** سوددهی در بک‌تست معیار قبولی این سند نیست. اول «درست اجرا شدن» را تأیید کنید، بعد با معیارهای خودتان (PF، expectancy، تعداد) استراتژی را بسنجید. اگر استراتژی در تستر ضررده بود، **روی دمو هم اجرا نکنید** مگر برای جمع‌آوری داده.

### ۲.۴ چه چیزی را از گزارش تستر استخراج کنیم

### ۳.۱ راه‌اندازی

### ۳.۳ معیارهای توقف فوری (Red Flags)

اگر هر کدام رخ داد، ربات را **خاموش** کنید و گزارش بدهید:

- دو ورود در یک کندل سیگنال
- ورود بدون SL
- ورود بعد از قفل روزانه
- عبور ضرر روزانه از سقف بدون قفل
- خطای `no money` تکرارشونده
- حجم معامله بیش از ۲ برابر محاسبه انتظاری
- معامله روی حساب واقعی بدون `InpEnableLiveTrading=true`

## سناریوهای تست هدفمند (T1–T14)

> این‌ها را روی **دمو** انجام دهید (نه تستر)، چون نیاز به دخالت دستی/ری‌استارت دارند.

### T1 — ری‌استارت وسط کندل
1. منتظر یک ورود موفق بمانید.
2. در همان کندل، EA را Remove و دوباره Attach کنید.
3. **انتظار:** هیچ ورود دومی روی همان کندل. لاگ `attach policy` و `lastEntryBar`.

### T2 — ری‌استارت بعد از سیگنال رد شده
1. با `InpMaxSpreadPoints=1` اسپرد را غیرممکن کنید تا سیگنال رد شود.
2. EA را ری‌استارت کنید.
3. **انتظار:** همان کندل دوباره معامله نمی‌شود (state = `lastEvalBar`).

### T3 — قطع اتصال / خاموشی ترمینال
1. دو ساعت ترمینال را ببندید (با پوزیشن باز).
2. باز کنید.
3. **انتظار:** پوزیشن شناسایی می‌شود، BE/تریل ادامه می‌یابد، هیچ پوزیشن تکراری باز نمی‌شود.

### T4 — واریز و برداشت
1. وسط روز دمو، ۵۰۰ دلار واریز کنید.
2. **انتظار:** سقف زیان روزانه بر مبنای بالانس شروع روز محاسبه می‌شود؛ واریز به‌عنوان سود/ضرر حساب نمی‌شود (لاگ `daily baseline` بدون هشدار).

### T5 — قفل روزانه
1. `InpMaxDailyLossPct=0.5` و `InpRiskPercent=0.5` بگذارید تا با یک ضرر قفل شود.
2. **انتظار:** بعد از ضرر، `DAILY LOSS LIMIT HIT` + بستن پوزیشن (اگر باز بود) + هیچ ورود جدید تا روز بعد.

### T6 — قفل دراودان
1. `InpMaxDrawdownPct=2` بگذارید.
2. **انتظار:** `MAX DRAWDOWN LIMIT HIT` و قفل دائمی تا `InpResetState=true`.

### T7 — اسپرد بالا
1. در ساعات خبری یا با `InpMaxSpreadPoints` کوچک تست کنید.
2. **انتظار:** `entry blocked: spread ... > limit` و تلاش مجدد محدود؛ بعد از اتمام، `signal skipped`.

### T8 — پوزیشن دستی روی حساب Netting
1. روی حساب Netting یک پوزیشن دستی ۰.۰۱ باز کنید.
2. **انتظار:** `foreign netting position ...` و **هیچ ورودی**. پوزیشن دستی بسته نمی‌شود.

### T9 — تغییر حجم پوزیشن از بیرون (Netting)
1. بعد از ورود EA، یک معامله دستی هم‌جهت ۰.۰۱ اضافه کنید.
2. **انتظار:** هشدار `volume grew ... external action` و رهاسازی مدیریت آن پوزیشن.

### T10 — حذف دستی SL/TP
1. SL پوزیشن را دستی حذف کنید.
2. **انتظار:** در چرخه بعدی، هشدار `NO stop loss` نیست چون ربات SL را دوباره می‌چسباند؛ اگر نشد، ERROR واضح.

### T11 — تغییر TP دستی
1. TP را دستی جابه‌جا کنید.
2. **انتظار:** BE بر اساس SL اولیه، نه TP جدید.

### T12 — حساب واقعی
1. روی حساب واقعی (با سرمایه کم یا حساب آزمایشی) Attach کنید.
2. **انتظار:** `REAL account detected ... EA refuses to start` و هیچ معامله‌ای.

### T13 — AutoTrading خاموش
1. دکمه AutoTrading را خاموش کنید، سیگنال بدهید.
2. **انتظار:** `terminal AutoTrading button is OFF`؛ هیچ سفارشی ارسال نمی‌شود.

### T14 — حداقل حجم بروکر
1. روی حسابی با حداقل لات ۰.۱ (یا با بالانس خیلی کم) اجرا کنید.
2. **انتظار:** پیام `min lot ... above the ... cap - trade skipped` و **عدم ورود** با ریسک بیش از حد.

| retcode | معنی | اقدام |
